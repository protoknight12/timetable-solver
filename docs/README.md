# Документация на SATurn

SATurn е уеб приложение, което съставя училищно седмично разписание. Администраторът въвежда данните на училището
и правилата (с формуляр или с обикновен текст на български), а програмата подрежда часовете така, че всички
задължителни правила да са спазени. Накрая независима проверка потвърждава, че разписанието е вярно.

Документацията описва версията в клон `main` към 26.11.2026 г. (началото на замразяването на функционалностите).
